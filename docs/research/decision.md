# STT/VAD decision and reproducible evaluation (YAV-6)

Status: research recommendation, pending Jason architecture/security acceptance and independent review. No production behavior is implemented by this change. Sources checked 2026-10-04. All measured evidence is synthetic VAD kernel work; no Turkish STT accuracy or microphone-latency result is claimed.

## ADR-R001: proposed baseline

Select **whisper.cpp v1.7.6, multilingual ggml-base.bin, and Silero VAD v6.0** for the initial Windows CPU evaluation. Use multilingual small as the quality comparison. These are existing permissively licensed components; exact code commits, model revision and file identity are below. Do not select an `.en` model for Turkish. This is an integration baseline, not a proven latency winner. Jason must accept or reject it after QA evidence. If true stateful partial decoding is a hard gate that rolling-window revisions cannot meet, evaluate Vosk before accepting Whisper.

Reasons: native Windows C/C++ deployment, explicit upstream MIT model grant, Turkish language support, and replaceable language-independent VAD. Whisper decoding remains rolling-window work: emitting provisional text every 500 ms does not mean a new word is recognized within 500 ms. Continuous redecoding can multiply compute and revise earlier text. Silence gating belongs in the worker and must prevent STT calls while retaining bounded pre-roll; a library VAD option alone does not prove low idle usage.

Alternative: Vosk small Turkish + WebRTC VAD is the strongest stateful-streaming comparator. Turkish quality is unknown (the publisher lists WER as TBD); choose it if measured responsiveness and accuracy meet Jason's accepted limits. Faster-whisper is the CPU-int8 / GPU throughput comparator, with a larger Python/CTranslate2 packaging surface. Sherpa-onnx is an attractive native ONNX framework, but streaming support of the framework does not make its offline Whisper model streaming.

## Actual experiment and limits

Only deterministic generated silence and Gaussian noise were used; no microphone or personal audio was captured. Machine: AMD Ryzen 7 6800H, 8 physical/16 logical cores, Windows build 26200. Python/package versions and all raw rows are in [vad-results.json](vad-results.json); environment is pinned in [bench-requirements.txt](bench-requirements.txt). CPUExecutionProvider, one ONNX intra/inter-op thread, Silero threshold 0.5, WebRTC mode 2. Seed 6006; noise standard deviation 327.68 PCM units (approximately -40 dBFS RMS). Each case uses 10 seconds at 16 kHz, first pass plus five warm passes. WebRTC frame 20 ms versus Silero 32 ms: compare cost per audio second as well as per frame; do not call these identical frame workloads. Incomplete Silero tail is dropped (16 ms). No pacing; elapsed time measures processing cost, not capture latency. Kernel timings include Python call/preparation overhead. No speech recall/precision conclusion follows from these inputs.

Reproduce from repository root in a disposable environment (download only public model bytes before offline evaluation):

```powershell
python -m venv .bench-env
.bench-env/Scripts/python -m pip install -r docs/research/bench-requirements.txt
curl.exe -L --fail https://raw.githubusercontent.com/snakers4/silero-vad/fba061dc5559f696e62171e9a0741782b0fdc23c/src/silero_vad/data/silero_vad.onnx -o silero_vad.onnx
.bench-env/Scripts/python docs/research/vad_microbench.py --model silero_vad.onnx > vad-results.json
```

The script verifies the model hash and outputs fixture hashes. Full cold process startup, OS file-cache-cold load, RAM and battery/idle CPU are **NM**. `init_ms` is object/session construction in a live process; first-pass is not cold-cache. Actual outputs are summarized separately in [verification.md](verification.md).

Access findings: initial `python` imports found none of vosk/faster_whisper/onnxruntime/webrtcvad/numpy. A disposable environment installed the VAD dependencies successfully. `cmake` was absent from PATH. No STT engine/model or licensed Turkish evaluation corpus was staged or run; these are unmeasured setup work, not proof of unavailable public models. No Windows microphone/session/service access test was attempted. `gh auth status` reported no login, but installed GitHub connector is ready and is the authorized publication route. No alternative model/CLI identity was impersonated.

## Reproducible benchmark design for QA

1. Freeze an evaluation manifest before testing: repository commit, engine and model hashes, Windows build, CPU/core topology, RAM, GPU/driver (if used), power plan, thread count, sample rate, device and buffer settings, VAD policy, decode beam/temperature/seed, language `tr`, normalization revision. Record package/wheel hashes and notices. Network acquisition is setup; disable runtime model auto-download. Restart with egress denied; verify inference still works and no audio/transcript traffic appears. No external prompt routing or TTS.
2. Dataset: freeze an explicitly redistributable public Turkish corpus revision and per-file PCM SHA-256, license and source URLs. QA selects and verifies this manifest before execution; no corpus is approved by this document. Predeclare at least 30 short utterances (1-5 s), 10 long passages (30-120 s), dialect/speaker strata and a speaker-disjoint tuning set. Include generated silence (60 s) and fixed-seed noise mixes at clean/20/10/0 dB SNR; speech onset/offset sample labels must survive resampling. Do not commit personal recordings or real private transcripts. Generated noise is not a substitute for noisy Turkish speech. Keep raw public-corpus files outside Git and publish only lawful aggregates/manifests.
3. Replay PCM in real time, identical inputs and randomised engine order. Use a single monotonic clock (`QueryPerformanceCounter`/`perf_counter_ns`) for sample delivery, detected onset, inference start/end, partial emission, stable-prefix change, speech offset and final output/flush. Source onset is sample-index mapped to the replay clock, not VAD detection time. UTC is only a run label; never subtract wall clocks or different process clock epochs without synchronization.
4. Report onset-to-first **nonempty** partial, onset-to-final and offset-to-final separately, plus VAD detection delay, inference queue time, dropped samples and partial revision/churn. A timestamp callback or empty event is not a partial. Preserve all hypotheses until scoring; measure stable-prefix latency separately so rapid incorrect guesses do not win. Whisper use step 500 ms/window 5 s as a starting experimental setting, not an SLO; test step/window grid on tuning data, then freeze. Vosk gets identical VAD segmentation and input pacing. Compare ungated controls so missed speech and pre-roll truncation are visible.
5. Warm condition: resident model, five untimed warm-up utterances then five measured corpus passes. Process-cold: 10 fresh process/model loads, include load separately. Cache-cold: separate reboot/cache-control procedure under QA control; never relabel process-cold as cache-cold. Publish p50/p95 and sample counts per condition/utterance stratum, paired confidence intervals over utterances, and all failures. Avoid percentile pooling across warm/cold or unequal corpus conditions.
6. Accuracy: raw and normalized WER/CER, fixed Unicode NFC and Turkish casing (`I` to `ı`, `İ` to `i`) policy, punctuation/numeral policy frozen and both raw/normalized scores retained. Score final utterances, missed words, hallucinations on silence and long-run duplicate text. VAD recall/precision and onset/offset error use labeled speech samples. Numeric accuracy and latency acceptance thresholds require Jason's sign-off before inspecting held-out results.
7. Resource metrics: wall/CPU time per audio second (RTF), process-tree private bytes and working-set peak at 100 ms intervals, CPU-seconds/wall-second plus explicitly normalized percent of logical capacity. Record idle capture+VAD baseline for 60 s and active STT separately, warm resident RAM versus unloaded. Prove zero STT inference calls during silence; baseline-subtract only with both raw values reported. GPU figures must include VRAM, synchronization and driver conditions.
8. Failures: test denied mic access, disconnect/reconnect, model corruption/hash mismatch, worker crash/restart, bounded queue overrun, long speech and interrupted output writes. Retain bounded pre-roll (proposed 300 ms), configurable silence hold (proposed 500 ms), and forced long-segment closure; these are tuning inputs, not accepted defaults. Retry must not duplicate finalized text. Write run results to a same-volume temporary file, flush, atomically rename; hash the manifest/results. Validate archives before any deletion.

Suggested result schema: run_id, fixture_hash, engine/model hashes, condition, repetition, onset_ns, vad_ns, first_partial_ns, stable_partial_ns, offset_ns, final_ns, flush_ns, cpu_ns, wall_ns, peak_private_bytes, peak_working_set_bytes, inference_calls_in_silence, partial_revisions, dropped_samples, WER/CER and failure_reason. Missing observations are null with reason, never zero. Per-engine STT cells remain NM until this protocol runs.
